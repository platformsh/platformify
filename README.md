# Platformify

> [!IMPORTANT]
> This project is no longer maintained. Its guided wizard has moved into the
> [Upsun CLI](https://github.com/upsun/cli), where it is available with `upsun init --ai=false`,
> but it will not get new features.
>
> To generate configuration, use `upsun init`, or an AI agent with the
> [Upsun AI toolkit](https://github.com/upsun/ai).

Get your project ready to be deployed in Platform.sh

## Building

In order to build the binary, use the following:

```console
go build ./cmd/platformify/
```

Run the CLI with:

```console
./platformify
```
